# WunnaGo v6 changes

- Bottom navigation is now fixed to the bottom of the viewport on Discover and Booking screens.
- It remains centered and capped to the app width on larger displays.
- Added iPhone safe-area support so the navigation does not collide with the home indicator.
- Added extra bottom spacing to scrollable content so buttons/content are not hidden beneath the fixed navigation.
- Toast notifications now sit above the fixed navigation.
